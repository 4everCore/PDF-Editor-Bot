# Debugging and QA issue log

This log records defects found during the repository review and external acceptance gates that remain unverified. A code fix is called verified only where the listed regression test passed locally.

## Fixed code defects

| ID | Severity | Location | Root cause / impact | Reproduction | Fix | Regression evidence |
|---|---|---|---|---|---|---|
| BUG-001 | HIGH | `app/storage/files.py`, `app/bot/handlers/files.py`, `app/processors/pdf/basic.py` | OOXML central-directory parsing (`ZipFile.infolist`) ran in the Telegram bot process before the entry-count check; a hostile archive could consume handler-process memory/CPU before worker limits applied. | Upload an OOXML ZIP with a pathological central directory; there was no safe locally executable high-load fixture. | Bot now performs cheap signature/size checks, and defers OOXML central-directory parsing/classification to the resource-limited `inspect` child operation. | `tests/unit/test_storage.py::test_ooxml_preflight_can_defer_archive_parsing`; `tests/integration/test_isolated_worker.py::test_ooxml_archive_preflight_runs_in_child`; handler upload tests. |
| BUG-002 | HIGH | `app/workers/worker.py::expire_files` | Hourly expiry could delete an expired source file while its queued/running job still referenced it, causing an otherwise valid job to fail. | Insert an expired file referenced by an active job and execute the expiry selection. | Expiry query excludes source files referenced by `queued`, `running`, or `cancelling` jobs. | `tests/integration/test_database.py::test_expiration_does_not_remove_source_used_by_active_job`. |
| BUG-003 | HIGH | `app/processors/pdf/external.py::LibreOfficeToPDF` | Concurrent conversions of the same source wrote LibreOffice's generated `<source-stem>.pdf` into the shared user storage directory, allowing one operation to overwrite/move another's intermediate output. | Run two conversions for the same source with different result destinations. | Each conversion uses an output directory keyed by the unique destination stem and removes it afterward. | `tests/unit/test_optional_adapters.py::test_concurrent_office_conversions_use_separate_output_directories`. |
| BUG-004 | MEDIUM | `app/workers/worker.py::process_document` | Cancellation while waiting for the local concurrency semaphore occurred before the worker's cancellation handler, leaving a job row stuck `running`/`cancelling`. | Cancel an Arq job while its coroutine waits on a zero-capacity semaphore. | `_job_slot` catches pre-slot cancellation, persists `cancelled`, and releases acquired capacity on every exit. | `tests/unit/test_worker_control.py::test_cancel_while_waiting_for_worker_slot_persists_cancelled_state`; `test_worker_slot_is_released_after_operation_error`. |
| BUG-005 | MEDIUM | `app/processors/pdf/basic.py::WatermarkPDF.execute` | `insert_textbox` can return a negative value when the watermark does not fit; the operation previously reported success and produced a PDF without the requested watermark. | Add a long watermark to a tiny page. | A non-fit now raises `ValidationError` and does not publish an output. | `tests/unit/test_pdf_operations.py::test_watermark_rejects_text_that_cannot_fit_small_page`. |
| BUG-006 | MEDIUM | `app/services/isolation.py`, `app/domain/operations.py`, `app/processors/pdf/external.py`, `app/processors/pdf/images.py`, `app/workers/worker.py` | Child imports depended on the parent's current working directory; subprocess scratch and operation-specific work artifacts could also remain after timeout/cancellation. | Start a child from outside the repository; time out a child; simulate aborted converter output workdirs. | Child `PYTHONPATH` uses the project root derived from the module, each child gets unique private `HOME`/`TMPDIR`, launcher cleans scratch in `finally`, and worker invokes operation-specific workspace cleanup for image/LibreOffice adapters. | `tests/integration/test_isolated_worker.py::test_worker_subprocess_executes_and_returns_metadata` changes CWD; `test_worker_timeout_kills_processor_process_group` asserts scratch removal; `tests/unit/test_optional_adapters.py::test_office_cleanup_removes_workdirs_left_by_aborted_child`; image conversion asserts intermediate cleanup. |
| BUG-007 | LOW | `Dockerfile` | The OS image installed OCRmyPDF via apt while Python extras independently installed OCRmyPDF via pip, creating two managed copies and ambiguous executable/package selection. | Inspect Docker build dependency layers; Docker is not installed here, so image behavior could not be reproduced. | Removed the duplicate apt `ocrmypdf` package; Python extra provides the CLI package, apt remains responsible for system OCR/PDF binaries. | Static Dockerfile review only; full Docker build remains blocked and this correction is not container-verified. |
| BUG-008 | HIGH | `app/workers/run_operation.py`, `app/processors/pdf/external.py`, `docker-compose.yml` | Output size was checked only after processor completion, so a hostile document could consume disk before the cap; OCR parallelism followed host CPU count and Compose had no worker PID ceiling. | A pathological PDF/OCR workload could create oversized intermediate files or excessive subprocesses; stress reproduction requires the absent system tools/container runtime. | Added per-file `RLIMIT_FSIZE` equal to the Telegram output cap, forces OCR to one job, and caps worker container PIDs. | Code/config review plus `tests/unit/test_optional_adapters.py::test_ocr_subprocess_parallelism_is_bounded`; hard-limit and Compose behavior still require Linux-container verification. |
| BUG-009 | MEDIUM | `.env.example`, `docker-compose.yml` | The example env file supplied a known non-empty PostgreSQL password, so Compose's required-variable check could pass without the operator replacing the sample secret. | Copy `.env.example` to `.env` unchanged and Compose accepts the fixed password value. | Blank password placeholder now causes Compose's `${POSTGRES_PASSWORD:?...}` guard to stop startup until a secret is set. | Static config review; actual Compose interpolation/build is blocked because Docker Compose is absent. |
